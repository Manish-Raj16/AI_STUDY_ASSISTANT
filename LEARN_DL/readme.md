# 📚 AI Study Assistant

An AI-powered Study Assistant built using

- Python
- Google Gemini
- Gradio

## Features

- Friendly mode
- Academic mode
- Secure API key using environment variables
- Gradio Web Interface

## Run Locally

```bash
pip install -r requirements.txt
```

Create a `.env`

```text
GEMINI_API_KEY=YOUR_API_KEY
```

Run

```bash
python app.py
```

Open

```
http://127.0.0.1:7860
```
